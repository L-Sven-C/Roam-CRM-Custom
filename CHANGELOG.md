# Changelog

## 1.2.0 - 2026-06-22

- Added configurable Contact Event Pages for automatic `last contacted::` updates from Daily Notes event blocks.
- Default Contact Event Pages: `call`, `1:1`, `group`, `meal`, `date`.

## 1.1.1 - 2026-06-22

- Fixed duplicate `contact frequency::` and `last contacted::` creation when fields are nested under `[[contact]]`.

## 1.1.0 - 2026-06-20

- Added the custom `[[metadata]]` template with `category:: #person` recognition.
- Added configurable CRM schema fields for people, contact reminders, agenda, and call templates.
- Added Chinese UI language support.
- Updated the bundled `extension.js` for direct Roam developer extension loading.

## 1.0.0 - 2026-06-20

- Created the MIT-compliant fork as Roam CRM Custom.
